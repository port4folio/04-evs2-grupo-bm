# CanchaPro

CanchaPro es una plataforma web orientada a la gestión y reserva de canchas deportivas.  
El sistema busca facilitar la experiencia de los usuarios permitiendo visualizar canchas disponibles, iniciar sesión y realizar reservas de manera rápida y sencilla.

---

# Objetivo del Proyecto

Desarrollar una aplicación web moderna para administrar reservas de canchas deportivas, mejorando la organización y experiencia de los usuarios.

---

# Funcionalidades Implementadas

- Página principal del sistema
- Inicio de sesión de usuarios
- Vista de reservas de canchas
- Diseño responsive
- Navegación entre páginas

---

# Tecnologías Utilizadas

- CSS3
